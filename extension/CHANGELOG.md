
# Change Log

All notable changes to the Code Equalize extension will be documented in this file.

## [0.0.1] - 2026-11-15

### Added
- Initial release of Code Equalize.
- AI-powered programming error explanations using Groq API.
- Multilingual error explanations.
- Context-aware debugging assistance.
- Retrieval-Augmented Generation (RAG) using ChromaDB.
- Support for Python, Java, C, and C++.
- Integration with the hosted backend deployed on Railway.
